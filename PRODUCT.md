# Orbitvo Tools / Image

## Product
Local-first browser tools for image compression, stitching, light PDF conversion, and publish prep. Files never leave the device by default.

## Audience
People who need quick, trustworthy compression and file prep (forms with KB limits, batch exports, PDF page extracts) without uploading to a third-party server.

## Mode
Operate (tool UI). Hub page may use a short Persuade line, then immediate tool cards.

## Platforms
Web (recent Chrome, Safari, Firefox, Edge). Static host: GitHub Pages at img.orbitvo.com.

## Must keep
- Local processing claim is true for all shipping tools
- Orbitvo brand link back to orbitvo.com
- Chinese UI as primary copy
- Free to use; no login or China payment in this phase

## Tools
1. Image compress (quality / target KB, batch, ZIP)
2. Merge images into one (row / column / grid)
3. PDF to images
4. Images to PDF
5. Convert & edit (format, crop, rotate, resize)

## Out of scope now
Membership, cloud AI default, video/audio, full PDF editor suite.
